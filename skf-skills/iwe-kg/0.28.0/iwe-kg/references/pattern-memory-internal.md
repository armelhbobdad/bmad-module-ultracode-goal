## The memory switch

- `enter_memory_store(cwd)`: when a `cwd` is given it must be an absolute directory, and the process `chdir`s into it; then `load_config()` runs and the graph loads; memory is **on only when a document with key `MEMORY` exists**. Its frontmatter is the knob mapping. [AST:crates/iwe/src/internal/claude/hook/store.rs:L105] [SRC:crates/iwe/src/internal/claude/hook/store.rs:L108] [SRC:crates/iwe/src/internal/claude/hook/store.rs:L111] [SRC:crates/iwe/src/internal/claude/hook/store.rs:L114] [SRC:crates/iwe/src/internal/claude/hook/store.rs:L125] [SRC:crates/iwe/src/internal/claude/hook/store.rs:L126]
- Because the switch goes through `load_config()`, a SessionStart hook run, or a PostToolUse run for a Write/Edit/MultiEdit of a `.md`/`.dj` file or for a Bash command with an `iwe create|update|rename|delete|attach` segment lacking `--strict` or an `iwe create|new` segment lacking `--dry-run`, in a workspace with an older config version migrates `.iwe/config.toml` in place. `iwe update ... --strict` or `iwe delete ... --strict` on its own does not reach `load_config()` from the hook. [SRC:crates/diwe/src/config.rs:L561] [SRC:crates/iwe/src/main.rs:L1628] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L37] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L41] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L12] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L13] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L176] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L182] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L67] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L71]

## enable: turning memory on

1. `--typed` cannot be combined with `--body`, `--config` or `--schema`. clap rejects the combination at parse time (`conflicts_with`) with exit 2, and the exit-1 refusals in `enable_memory` are only a fallback for non-CLI callers. [SRC:crates/iwe/src/main.rs:L188] [SRC:crates/iwe/src/main.rs:L206] [SRC:crates/iwe/src/main.rs:L214] [SRC:crates/iwe/src/internal/claude/enable.rs:L61] [SRC:crates/iwe/src/internal/claude/enable.rs:L65]
2. With neither `iwe.toml` nor `.iwe/`, it runs `init_workspace` with `use_defaults` and rewrites the config's date formats to ISO "so timestamps compare". [SRC:crates/iwe/src/internal/claude/enable.rs:L113] [SRC:crates/iwe/src/internal/claude/enable.rs:L119] [SRC:crates/iwe/src/internal/claude/enable.rs:L135]
3. An existing `MEMORY.<ext>` in the workspace ends it with exit `2`: `already memory-enabled`. [SRC:crates/iwe/src/internal/claude/enable.rs:L151]
4. Ontology: `--typed` installs the typed config and four schemas, and `--config`/`--schema` install a composed one. With none of these flags and no `--body`, enable installs the starter `memory` schema unless `.iwe/config.toml` already has a `[schemas.memory]` line or `.iwe/schemas/memory.yaml` exists. In that case it prints `kept the memory schema this workspace already binds`; a schema bound under another name does not stop the install. `--body` with no `--config`/`--schema` installs no schema. When the workspace binds no schema at all, enable checks the body first. If any body line holds both `iwe ` and `--strict`, it prints `error: this policy tells the agent to pass --strict, but no schema binds in this workspace` and a remedy line, then exits `1` without writing `MEMORY.md`. Otherwise it prints `no schema installed — ...` and carries on. When a schema is already bound, `--body` goes ahead silently. [SRC:crates/iwe/src/internal/claude/enable.rs:L20] [SRC:crates/iwe/src/internal/claude/enable.rs:L180] [SRC:crates/iwe/src/internal/claude/enable.rs:L182] [SRC:crates/iwe/src/internal/claude/enable.rs:L187] [SRC:crates/iwe/src/internal/claude/enable.rs:L194] [SRC:crates/iwe/src/internal/claude/enable.rs:L195] [SRC:crates/iwe/src/internal/claude/enable.rs:L197] [SRC:crates/iwe/src/internal/claude/enable.rs:L202] [SRC:crates/iwe/src/internal/claude/enable.rs:L204] [SRC:crates/iwe/src/internal/claude/enable.rs:L226] [SRC:crates/iwe/src/internal/claude/enable.rs:L256] [SRC:crates/iwe/src/internal/claude/enable.rs:L261]
5. `MEMORY.md` is written as `---\nKNOBS---\n\nBODY` (starter, typed or `--body`), the state directory's `.gitignore` is ensured, and `--queries` adds the `queries` cookbook. [SRC:crates/iwe/src/internal/claude/enable.rs:L217] [SRC:crates/iwe/src/internal/claude/enable.rs:L226] [SRC:crates/iwe/src/internal/claude/enable.rs:L230] [SRC:crates/iwe/src/internal/claude/enable.rs:L240]
6. It prints `nothing outside the store was touched`. [SRC:crates/iwe/src/internal/claude/enable.rs:L243]

## PostToolUse hook behaviour

- Only `tool_name` `Write`, `Edit`, `MultiEdit` and `Bash` are looked at. [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L11] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L28]
- Editor tools: a `.md`/`.dj` file inside the workspace with the configured extension, other than `MEMORY`, is schema-checked; a failure reports `iwe: KEY does not match its schema`. The file is **not rewritten**. [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L37] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L43] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L49] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L55] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L58] [SRC:crates/iwe/CHANGELOG.md:L42]
- Bash: for an `iwe create|update|rename|delete|attach` segment without `--strict`, the keys the command printed are schema-checked. Each failing key adds `iwe: KEY does not match its schema` and its schema report; if any key fails, the "That write ran without `--strict` ... put the flag on every write" context is added once. Passing keys add nothing. The similar-page check that follows also runs for an `iwe create|new` segment, so the hook prints nothing only when neither check found anything. For `iwe create|new` without `--dry-run`, each written key that closely matches another document gets `iwe: KEY › similar-page: closely matches 'OTHER' (score)`. The context names OTHER and tells the agent to keep the older key and merge as the policy's dedup section says. The hook does not decide which key is older. [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L12] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L13] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L65] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L66] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L86] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L95] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L103] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L108] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L114] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L116] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L126] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L176] [SRC:crates/iwe/src/internal/claude/hook/post_tool.rs:L182] [SRC:crates/diwe/src/stats.rs:L344]
